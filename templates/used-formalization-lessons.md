# Used Formalization Lessons

This file is written in a new paper repo when that repo tried existing
meta-library formalization versions.

For each targeted older version, use a heading containing the exact target:

```text
## MetaLibrary.Papers.TemplatePaper.v1a1.Surface
```

Then record practical lessons about using that version. During import, these
notes are appended to the target version's
`downstream-hard-earned-lessons.md`.
