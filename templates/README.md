# Submission Templates

These files are starting points for a paper repository that will be submitted
through the import site.

- `metadata-meta-library.yaml`: required submission metadata
- `Surface.lean`: alias-only export surface
- `theorem-list.json`: structured exported theorem and definition list
- `surface-readme.md`: human usage notes for the accepted surface
- `hard-earned-lessons.md`: notes from creating this formalization
- `used-formalizations.json`: structured feedback about older meta-library
  formalizations tried by this paper repo
- `used-formalization-lessons.md`: longer reuse notes for older formalizations

The main meta-library repository keeps accepted version folders after import.
This directory is for preparing candidate paper repositories before import.
